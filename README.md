## 替换头像 / CV
在 profile.js 中设置 photoUrl 为 images/profile.jpg，将本人头像放入该路径。设置 cvUrl 为 files/CV_Haozhe_Xu.pdf，将本人 CV 放入该路径。头像目前完全留空；CV 页面等待文件。Scholar 和 GitHub 链接也在 profile.js 中配置。

## 访问统计
在线托管版本使用持久数据库计数，显示累计网页浏览次数和香港时区的今日浏览次数。每次页面加载记一次，栏目切换、图片加载和查询统计不会增加计数。这是浏览次数而非独立访客数；不收集 IP 或访客身份。统计从本次启用开始，旧版本访问量无法追溯。离线或仅在 GitHub Pages 上使用本包时，没有统计后端，会显示 Statistics unavailable。请勿将显示值改成虚构计数。
